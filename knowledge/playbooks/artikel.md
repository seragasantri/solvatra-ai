# Playbook: Artikel blog & SEO (Bahasa Indonesia)

## Alur
1. **Maksud pencarian** — apa yang dicari pembaca? (cara, panduan, perbandingan, definisi). Jawab maksud itu dalam 100 kata pertama.
2. **Kata kunci** — satu kata kunci utama + 3–5 pendukung. Pakai di judul, pembuka, satu sub-judul, dan meta description. Jangan menjejalkan.
3. **Kerangka** — H1 (judul), H2 per gagasan, H3 untuk langkah. Paragraf pendek (2–4 kalimat).
4. **Tulis** — kalimat aktif, sebagian besar ≤ 20 kata. Daftar atau tabel untuk langkah dan perbandingan.
5. **Penutup** — ringkasan 3 poin + ajakan bertindak (bukan "demikian artikel ini").
6. **FAQ** — 3–5 pertanyaan bila topiknya sering dicari.

## Format
- Judul ≤ 60 karakter, memuat kata kunci utama.
- Meta description 140–160 karakter.
- Satu H1; H2/H3 memakai variasi kata kunci secara wajar.

## Aturan
- Jangan mengarang statistik, kutipan, sumber, atau URL. Data belum terverifikasi ditandai `[verifikasi]`.
- Tautan internal/eksternal disarankan, tapi jangan membuat URL yang tidak diberikan pengguna.
- Sesuaikan nada dengan pembaca (formal untuk bisnis, santai untuk konsumen).

## Checklist
- [ ] Jawaban utama ada di 100 kata pertama
- [ ] Judul dan meta description sesuai panjang
- [ ] Satu H1, H2 jelas, paragraf pendek
- [ ] Tidak ada klaim atau angka tanpa dasar
- [ ] Penutup berisi ajakan bertindak
